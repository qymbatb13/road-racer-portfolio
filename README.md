# Road Racer portfolio

This repository contains a single-page portfolio for the mobile game "Road Racer".

What is included (placeholders):

- `index.html` — single-page portfolio with placeholders for screenshots, text, and links.
- `screenshots/` — directory for game screenshots (not included). Add your images here and they will appear on the page.

How to use

1. Replace placeholders in `index.html`:
   - Update your name, email, tagline, case study text and metrics.
   - Replace the images in `screenshots/` with your actual screenshots. Recommended names:
     - `roadracer_phone_preview.jpg`
     - `roadracer_garage.jpg`
     - `roadracer_pause.jpg`
     - `roadracer_gameplay.jpg`
     - `roadracer_settings.jpg`
     - `roadracer_garage_blue.jpg`

2. Preview locally: open `index.html` in a browser.

3. Deploy with GitHub Pages:
   - In the repo settings -> Pages, set the source to the `main` branch and `/ (root)`.
